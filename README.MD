# Projeto Morro de São Paulo

Esse projeto foi feito para uma atividade do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

A ideia foi criar uma página simples em HTML falando um pouco sobre **Morro de São Paulo**, mostrando algumas informações sobre o lugar, suas praias e alguns pontos turísticos.

## O que foi usado

* HTML5

## Estrutura do projeto


morro-de-sao-paulo/
│
├── index.html
├── sobre.html
└── imagens/


## Sobre o site

Na página coloquei:

* Uma apresentação sobre Morro de São Paulo
* Informações sobre as praias
* Algumas atividades que podem ser feitas no local
* Um formulário simples de contato
* Menu para navegar pelas partes da página



## Objetivo

O objetivo desse projeto foi colocar em prática o que estou aprendendo em HTML  no curso de ADS do Senai Cimatec, principalmente a criação da estrutura de uma página, links, formulários e organização do conteúdo.
